# homebrew-devbridge

Homebrew tap for the [devbridge](https://github.com/adityaraja338/devbridge) Mac agent.

```
brew install adityaraja338/devbridge/devbridge-agent
devbridge-agent setup
brew services start devbridge-agent
devbridge-agent pair
```

`Formula/devbridge-agent.rb` is generated by devbridge's release workflow from
`packaging/homebrew/devbridge-agent.rb.tmpl`; edit the template there, not this file.
